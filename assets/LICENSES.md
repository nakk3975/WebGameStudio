# 에셋과 의존성

- 사건/대화 텍스트: 사용자가 제공한 기획서의 허구 사례를 바탕으로 작성.
- 시계 비교 자료와 배경: 직접 작성한 CSS/텍스트 컴포넌트. 외부 이미지 없음.
- UI 아이콘: lucide-react, ISC. 원본 패키지 라이선스는 배포 소스의 package-lock.json에 해당 버전이 고정되어 있음.
- React/React DOM/Vite/Vitest/Zod/React Flow: 각 패키지의 배포 LICENSE를 준수. dependency-licenses.json에 설치 버전과 라이선스 식별자를 기록.
- 외부 폰트를 다운로드하거나 번들에 넣지 않음. 시스템 글꼴 사용.
- 사용자 업로드, 원격 에셋, 음악/효과음 없음.
