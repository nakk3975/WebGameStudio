## 공통 표시 수정

- 모든 공식 사건에서 TXT/로그의 사진은 ‘사진 자료’ 폴더와 별도 창으로 연다.
- CAM 기록의 영상 재생은 그대로 제공한다. 영상은 사진 폴더에 섞지 않는다.
- 현장 사진 뷰어에 접근 가능한 다른 사진/영상이 자동으로 합쳐지던 갤러리를 제거했다.
- 사진은 해당 원본 파일이 공개되고 상위 폴더 잠금이 해제된 경우에만 노출된다.

## 자산 생성 기록

기본 제공 imagegen 도구로 다음 사진을 수정한 후 WebP로 인코딩했다. CLI/API 대체 생성은 사용하지 않았다.

- `apps/ghostdesk/src/assets/lab.webp`: 작은 탁상시계만 제거, 두 PC·NAS·분리된 RJ45·문서 배치 유지.
- `apps/ghostdesk/src/assets/auction-seals.webp`: 그림만 청색 궤도 추상화로 교체. 세 봉인의 한 줄/두 줄 정상/두 줄 파손과 상대 위치 유지.
- `apps/ghostdesk/src/assets/auction-envelopes.webp`: 같은 청색 작품, 이전판의 정상 무표식 봉인 세 개 유지.
- `apps/ghostdesk/src/assets/island.webp`: 수신기 영상의 전면 디자인과 부표 사진의 주황 부체·기록함·안테나를 참조해 두 물체 교체. 기존 구도·노트·밧줄 유지, 세 번째 아침의 해초 추가.

공연·수신기 영상은 `scripts/render-recordings.py`의 Blender 장면으로 다시 렌더링했다.
공연 사진은 같은 장면의 `--stills`(22:03 공연 종료 후 조명)로 생성했다.
`scripts/build-recordings.py`는 모든 영상 포스터를 인코딩 완료 MP4에서 무손실 WebP로 추출한다.
`auction-display.webp` 등 예전 장식 자산을 최신 공식 사건의 증거로 다시 연결하지 않는다.
